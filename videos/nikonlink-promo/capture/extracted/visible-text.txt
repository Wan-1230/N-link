N-Link 宣传种草视频需求（用户原始 brief）：

为当前项目生成一套官方宣传种草短视频脚本，主打新手友好、功能实用、高效便捷，面向普通终端用户/开发者用户，核心目的是吸引用户下载体验、长期使用本软件。

视频风格：简约科技/极简商务/清新轻量化，动态微动效，界面演示真实还原软件操作，无浮夸特效，沉浸式展示软件使用体验。

脚本输出规范：
- 按时间轴逐秒拆分分镜，精准标注每段镜头时长；
- 画面描述贴合 Hyperframes 生成逻辑，明确界面展示、操作动作、动态效果、画面构图；
- 配套专属字幕、旁白、BGM 风格、转场特效，全程适配 AI 视频渲染；
- 开头悬念/痛点引入、中段功能价值展示、结尾引流引导，完整闭环宣传逻辑。

用户确认：16:9 横屏 / 约 60 秒 / 字幕+BGM（无配音）。

应用核心卖点（PRD）：
- 稳：连接恢复 < 3 秒，后台存活率 > 99%，断联自动指数退避重连
- 快：WiFi 5GHz 传输 > 10MB/s，Live View 延迟 < 200ms，遥控快门 < 150ms
- 全：照片传输 + 遥控拍摄 + 实时取景 + 参数管理四合一
- 简：一次配对永久连接，零操作自动恢复；WiFi AP / WiFi STA / USB 三通道教程引导，新手友好

界面结构（真实布局蓝本）：
- Tab1 设备：我的设备标题栏 / 连接模式药丸 Tab（WiFi AP·WiFi STA·USB）/ 教程卡片 / 扫描相机+连接相机按钮 / 纯黑设备核心卡片（状态点、相机名、电量、存储卡、剩余可拍、镜头）/ 2x2 快捷网格（遥控拍摄·查看相册·固件更新·位置同步）/ 相机详情折叠组
- Tab2 相机照片：分类胶囊标签 / 3 列影像网格 / 相机照片·本地照片分段 / 多选悬浮操作栏（下载·删除·分享·全选）/ 下载进度条
- Tab3 拍摄：照片·视频模式药丸 / 实时取景区（电量·剩余·连接 scrim 信息、录制徽标、触摸对焦点、开始监看、全屏）/ 参数控制区（快门按钮、光圈·快门·ISO 拨盘）
- Tab4 设置：参数列表
- 底部 Tab 栏：设备 / 相机照片 / 拍摄 / 设置（图标+10sp 文字，顶部 1px 分割线）
