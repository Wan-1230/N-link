## 2. 参考结论与差异化建议

> 依据 `docs/CONTRIBUTING.md`「外部产品信息不入库」：本节原先记录的外部产品实机取证、
> 版本级对照对象清单与静态认知已移除。以下保留的是**不依赖具体产品**的行业通识，
> 以及本项目自己的差异化决策 —— 它们是 §3 实施路径的取舍依据，缺了会让后面的
> 「为什么这样收口」失去出处。

### 大厂感共性（行业范式通识，非逐条对照某产品）
1. **一个页面只有一个视觉重心**：首页 = 英雄区 + **一枚**主 CTA；其余全部退到灰阶。强调色全 App 只有一支，出现位置 ≈ 3 类（主按钮/选中态/链接）。
2. **空态是设计组件不是提示文字**：图标容器（72dp 圆角方块）+ 粗标题 + 引导副文案 + 行动按钮；网格 3px 缝隙全出血、无卡片包边。
3. **克制的动效**：只有按压反馈、tab 切换、进度流动三类；时长统一在 150-400ms，曲线一致，无弹跳滥用。
4. **排版层级 ≤5 档**、间距严格 4/8 倍数、卡片圆角统一——"统一"本身就是高级感的来源。
5. **首屏零等待感**：无相机时页面立即完整渲染（英雄图+按钮常驻），数据区才进入加载/空态。

### 我们的差异化（不走深色赛博，走自己的"黑白灰+黄"）
- **浅色工作台路线**：浅色为主、黑白灰+尼康黄，在一众深色相机 App 里反而构成辨识度（走「平面设计式」克制路线而非「产品渲染式」路线）。深色模式按规范同值映射，不另造氛围。
- **强调色纪律更强**：锁死「状态灯 + 主按钮」两处（规范 §1.1），选中态一律黑/白 chip——比常见同类做法更克制，形成自己的签名。
- **玻璃材质是我们的独有资产**：GlassTokens L1/L2/L3 + 运行时降级构成层级语言，dock/顶栏/操作栏三处玻璃即可，不扩大使用面（材质稀缺感 = 高级感）。
- **信息密度专业向**：相机传图工具要"参数可见"（速率/频段/进度环），比通用相册多一层专业仪表感——这是属于我们的差异化。

### 2.5 连接 UX 简化（2026-10-04~07 落地，v1 未覆盖的范围，入册）

前端优化不止像素——**把"要用户做的操作"降到一次点击**是更大的一档质感提升。此范围由连接排障催生，已完成并入册：

| 项 | 内容 | 提交 |
|---|---|---|
| 单按钮连接 | 三个页签只留「连接相机」：AP=一键直连/拉系统面板；STA=自动搜索（mDNS+网段）+自动接续；USB=检测即连。「扫描相机」退役（保留布局便于回退） | `435bc66` |
| 失败可解释 | AP 档失败按探测档位分级文案（未响应/超时/无路由）；蜂窝黑洞立即收口（不再 173s 空转）；失败后自动重发现一次并接续 | `130a879` |
| 防死亡螺旋 | 会话活着/握手进行中时重复点击被拒绝并提示——参考实现的单飞闸语义；此前连点会拆掉刚建立的会话，相机端半开会话反噬下一代连接（event_read_error 2~7s 反复） | `130a879` |
| 闸门收敛 | 35 个开发选项裁到 5 个真实验项；已验证修复锁进 `ConnFlags.LOCKED`（无视 prefs 残留） | `1736eb3` |

**验收口径**（真机）：① STA 场景点一次按钮完成发现+接续；② 连上后连点不再掉线（状态行提示"相机已连接"）；③ 相机不在网时 ~15s 内出明确文案；④ 每项在 `n-link_logs` 导出物中有对应事件可查（`connect_ignored reason=session_live` / `no_camera_subnet` / `auto_rediscover`）。

## 附：刻意不做的事

- **不引入 Compose / 不换图片库**：自研 ThumbnailCache 质量高于平均水准（LRU+磁盘+降采样+fling 暂停），迁移是风险不是收益
- **不推翻黑白灰+黄**：这是 v2.6.5 已拍板的品牌决策，本方案所有设计结论都在强化它而非替代它
- **不做全 App 大重排**：已真机验收的布局不动，质感提升走 token 渗透 + 三态 + 微交互三条线
- **不上移动端埋点 SDK**：与「无云端依赖」卖点冲突，UI 指标走既有 FR-08d 本地导出物
