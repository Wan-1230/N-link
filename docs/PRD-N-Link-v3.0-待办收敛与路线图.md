**用法（铁律）**：新增提案指不到 P1–P4 或 S1–S6 的某一行 → 不进本期；反过来，本文 M0~M5 每一条都应能反查到一格——10-03 逐条比对的唯一例外是 **S6 无对应条目**，已列为缺口。
**画像分布判断【推】**：P1 是现金流与口碑来源（也被官方免费化打得最狠），P2/P3 正被停更开源同路与付费对手分头拿走，P4 是替我们传播的一群。**顺序不能反：P1 掉了没人替我们说话，P4 掉了没人替我们证明。**
