# 尼康云创（Nikon Imaging Cloud）接入可行性评估

| 项 | 内容 |
| --- | --- |
| 评估对象 | Nikon Imaging Cloud（尼康云创）第三方 App 接入可行性 |
| 评估时间 | 2026-08-30 |
| 评估结论 | **不可行，不建议实现** |
| 阻塞级别 | 核心级（非工程量问题） |

---

## 1. 结论摘要

尼康云创是尼康自家的**相机直连云服务平台**，设计上不存在"第三方 App 调用云 API"的接口。当前无公开 API、无第三方 OAuth 客户端注册入口、无开发者计划。唯一官方开放渠道（`sdk.nikonimaging.com`）只覆盖桌面端本机遥控，**不含任何云服务**。

阻塞点为核心级（B1/B2/B3），短期无解。本报告不改动任何业务代码。

---

## 2. 服务形态调研

### 2.1 官方定位

官网：`https://imagingcloud.nikon.com`（中国区 `https://imagingcloud.nikon.com.cn`）

尼康官方文档对云创的描述（Z5II / Z6III / ZR 在线说明书「雲端服務」章节）：

> Nikon Imaging Cloud 是可在電腦或智慧型裝置的**網頁瀏覽器**中使用的尼康雲端服務。

注意关键词是**网页浏览器**——服务入口是 Web，不是 API。

### 2.2 四类能力及其数据流向

| 能力 | 说明 | 数据流向 | 第三方可介入？ |
| --- | --- | --- | --- |
| 影像传输 | 照片暂存云端（免费 30 天），自动转发到第三方网盘 | **相机 → 云 → 网盘** | ❌ 不经过手机 App |
| 成像配方 / 色彩方案 | 云端 Picture Control 预设，下载到机身（最多 9 个） | 云 → 相机 | ❌ 相机侧完成 |
| 固件更新 | 云端推送固件到相机 | 云 → 相机 | ❌ 相机侧完成 |
| 真实性服务（C2PA） | 为照片附加内容凭证 | 相机侧 | ❌ 相机侧完成 |

**关键点：所有能力的发起方都是相机或 Web 浏览器。** 影像传输尤其如此——相机通过自身 Wi-Fi 直连上传到云，手机 App 在这条链路上没有任何位置。

### 2.3 兼容机型

Z6III / Z50II / Z5II / Zf / ZR

共 5 款。而 N-Link 面向的机型更广（Z5/Z6/Z6II/Z7/Z7II/Z8/Z9/Z30/Z50/Zfc 等），即便接入成功，收益面也有限。

## 3. 认证方式（实测）

### 3.1 实测过程

```
curl -sIL "https://auth.cld.nikon.com/.well-known/openid-configuration"
```

### 3.2 实测结果

```
HTTP/1.1 302  → Location: https://accounts.cld.nikon.com/login          (CloudFront)
HTTP/1.1 302  → Location: /login/complete                                (nginx)
HTTP/1.1 302  → Location: /sso/login                                     (nginx)
HTTP/1.1 302  → Location: https://auth.accounts.cld.nikon.com/auth/realms/user/
                          protocol/openid-connect/auth
                          ?response_type=code
                          &client_id=c0001
                          &redirect_uri=https://accounts.cld.nikon.com/sso/login
                          &state=...
                          &login=true
                          &scope=openid
HTTP/1.1 200  (text/html)
```

### 3.3 结论

- 认证体系是 **Keycloak**，realm 为 `user`
- 授权模式：**Authorization Code + PKCE 的标准 OIDC**
- `client_id=c0001` 是**尼康第一方 Web 应用**的公共客户端
- 该 realm 下**没有面向第三方开发者的 client 注册入口**（`.well-known/openid-configuration` 本身返回 302，说明连发现端点都不对外提供服务）

## 4. 技术阻塞点

| # | 阻塞点 | 详细说明 | 级别 |
| --- | --- | --- | --- |
| **B1** | **无公开 API** | 尼康未发布任何 Nikon Imaging Cloud 的 REST / GraphQL API 文档、OpenAPI 规格或开发者门户。所有功能由 Web 前端内部调用，接口未对外暴露 | 核心 |
| **B2** | **无第三方 OAuth 客户端注册** | Keycloak realm `user` 下没有第三方 client 注册流程。App 要拿 token 只能复用第一方 `client_id=c0001`，属**未授权访问他人服务** | 核心 |
| **B3** | **合规与 ToS 风险** | 逆向并复用第一方 client_id、模拟 Web 前端调用，违反尼康服务条款，且属"绕过技术保护措施"。对开源项目是不可接受的法律风险 | 核心 |
| **B4** | **数据同步范围不可介入** | 「影像传输」由**相机直连 Wi-Fi 上传**完成，云端仅作中转。照片流不经过手机 App，第三方在链路上没有位置，无法"接管"或"同步"这部分数据 | 架构 |
| **B5** | **凭据无法合法获取** | 即便逆向成功，token 有效期、刷新机制、风控策略均由尼康单方面控制，随时失效，无法作为产品功能交付 | 工程 |
| **B6** | **机型覆盖面过窄** | 仅 Z6III/Z50II/Z5II/Zf/ZR 五款支持，与 N-Link 的目标机型重合度低 | 商业 |

## 5. 唯一官方开放渠道（不含云服务）

`sdk.nikonimaging.com/apply/` 提供尼康 SDK 免费下载（需申请流程）。

**覆盖范围**：

- 数码单反 / 微单的**遥控功能** Library Programs
- Command API 规格
- 桌面端（Windows / macOS）库

**明确限制**：

- 官方声明 **不提供技术支持**
- **不包含任何云创 / 云服务接口**
- 不覆盖 Android / 移动端

即：这条路只能增强本机遥控能力，与"接入尼康云创"是两回事。

## 6. 建议的替代路径

| 优先级 | 方案 | 说明 | 前置依赖 | 风险 |
| --- | --- | --- | --- | --- |
| **P1** | **云创网页入口** | 设置页增加「尼康云创」入口卡片，`ACTION_VIEW` 跳转 `https://imagingcloud.nikon.com(.cn)`。只读、零认证、零数据、零风险 | 无 | 无 |
| **P2** | **标准网盘直传** | App 内已下载的照片一键 / 自动上传到用户自己的网盘（OneDrive / Dropbox / Google Photos / 阿里云盘 / 腾讯云 COS）。这些平台均有公开 API 与正规 OAuth 注册 | 各平台 OAuth 应用注册 | 低 |
| **P2** | **申请尼康官方 SDK** | 向 `sdk.nikonimaging.com` 提交申请，获取 Command API 规格，用于增强本机遥控能力 | 尼康审批 + 接受"无官方支持" | 中 |
| **P3** | **持续观望** | 关注尼康是否开放开发者计划；若开放，重新评估 | — | — |

> P1 若落地，需与「检查更新」分支协商 `SettingsFragment.kt` / `fragment_settings.xml` 的改动顺序（建议串行），以维持文件互不重叠的约束。本版本未实施。
