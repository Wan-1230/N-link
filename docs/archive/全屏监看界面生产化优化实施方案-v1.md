## 〇、总评与生产底线判定

`LiveViewManager`（922 行）的**链路容错已达生产级**：三通道（USB/AP/WiFi）分级容错、拍照宽限、录像期望停流、就地重启码流、End/Start 顺序收敛——这部分不是本方案重点。监看界面的短板集中在**渲染链**与**未经真机验证**两点：

| 生产底线项      | 现状                                                                              | 判定                  |
| ---------- | ------------------------------------------------------------------------------- | ------------------- |
| 新 HUD 真机走查 | `07e2b9e` 重构后**从未真机验证**（v3.0 M0 0.6 未跑）                                         | ❌ 未达生产底线            |
| 主线程负载      | 每帧全尺寸 JPEG 解码 + ImageView 上屏跑在主线程（下方 §3.2 实证）                                   | ❌ 中低端机掉帧/ANR 风险     |
| 旋屏连续性      | 旋屏 = 停流重启，黑屏约 1-2s（下方 §3.4 实证）                                                  | ❌ 高频操作断裂            |
| 静默失败       | 模式入口静默已修（`8d874fb`）；错误路径有内联状态卡 + Toast                                          | ✅ 基本达标              |
| 量化基线       | 监看超轮率仅日志样本 16.1%→49.6%，无可信基线（v2.7 P0-3 未跑）                                      | ❌ 无基线               |
| 色板/可访问性债   | lv\_* 夜间豁免、黄例外登记、contentDescription **均已完成**（本轮核对 colors.xml:98-108 / 布局 6+6 处） | ✅ v1.2/v3.0 相关条目可关闭 |

**结论：监看界面「链路层可上线、UI 层差一轮生产化」。** 本方案分三批：**A 生产底线（不碰渲染链）→ B 渲染链重构（单链批改）→ C 专业能力与布局合一**。A 批完成即可达到「生产环境可用」；B/C 是「生产环境好用」。

## 七、回滚与风险总则

- 每项独立 commit：`git revert <hash>` 单点回退，与 v1.2 规划同手段。
- B2 上屏路径若坐标迁移回归失败 → 整体回退 B2/B3，保留 B1（解码异步化可独立成立）。
- B3 帧率自适应若弱链路抖动 → 闸门 `LV_ADAPTIVE_FPS` 一键回退固定 66ms。
- C2 开闸帧率劣化 → 回退 `TONE_TOOLS=false`，功能代码保留。
- 真机走查（A1）发现的新问题一律先登记再排期，不在当批顺手改（防范围蔓延）。

## 八、刻意不做

- **不引第三方播放器/相机框架**：监看帧是 PTP 拉取的 JPEG 序列，不是视频流；GL 上屏只为零拷贝，不引库。
- **不重写 Manager 链路层**：三通道容错已生产级，本方案只做 UI/渲染/生命周期。
- **不做多镜头/多机型差异化 HUD**：走查清单只覆盖既有能力。
- **B 批不顺手做工具**：单链不两改，工具全部等 B 定案。
- **不动已登记的色板例外**（lv_accent 黄、lv\_* 恒黑）：注释已在，属决策非缺陷。

**关键设计决策**

1. **斑马纹用黑白交替斜纹而非单色块**：单色块压在同色底上会整片消失；斜纹靠亮度翻转传信息，压任何底色都可见，且**不需要色相** → 不必动用「画面测量层可用彩色」的例外。
2. **峰值用红（有意例外）**：必须与画面色相拉开，否则描在红花上的红描边等于没画。性质与伪彩相同（规范管界面元件，不管画面测量叠加层），已在 KDoc 登记。
3. **三者不挂 `UiFlags.TONE_TOOLS`**：那是影调类闸门；绑过去会让"只想看安全框"的用户被迫打开整套影调工具。
4. **叠加层可见性统一收口**：原先 `if (gridVisible || toneOn)` 散在三处（`toolGrid` 点击、`applyPseudoColorToggle`、`showControls`），关网格会顺手藏掉伪彩/安全框。现统一走 `syncOverlayVisibility()`。
